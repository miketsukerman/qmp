# VERIFY register

Every assumption about QNX SDP 8.0 or uProtocol that the design relies on, with the result of
checking it on the real platform or against the pinned spec. Code sites carry `/* VERIFY(qnx8): V-QNX-nnn */` or
`/* VERIFY(up): V-UP-nnn */` comments pointing here.

Status values: `open` · `analysed` (docs read, target result pending) · `partially confirmed` (which part is still open is stated) · `confirmed` · `refuted` (with the fix) · `n/a`.
The "where" column names the file and function; line numbers are left out because they move.
