# VERIFY register

Every assumption about QNX SDP 8.0 or uProtocol that is not yet confirmed on the real platform
or against the pinned spec. Code sites carry `/* VERIFY(qnx8): V-QNX-nnn */` or
`/* VERIFY(up): V-UP-nnn */` comments pointing here.

Status values: `open` · `confirmed` · `refuted` (with the fix) · `n/a`.
"file:line" is filled in when the code exists; until then the design section is referenced.
